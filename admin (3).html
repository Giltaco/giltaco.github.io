⚙️ Configuración Inicial

Antes de usar el panel admin, necesitas configurar tu proyecto de Supabase. Sigue estos pasos:

1. Ve a supabase.com, crea una cuenta gratuita y un nuevo proyecto.
2. En tu proyecto de Supabase, ve a SQL Editor y ejecuta el siguiente SQL para crear las tablas:

-- Copia el SQL de abajo y pégalo en el SQL Editor
create table categorias ( id uuid primary key default gen_random_uuid(), nombre text not null, emoji text default '💄', slug text unique not null, orden int default 0, created_at timestamptz default now() ); create table productos ( id uuid primary key default gen_random_uuid(), categoria_id uuid references categorias(id) on delete set null, nombre text not null, marca text, descripcion text, precio numeric default 0, precio_anterior numeric default 0, imagen_url text, emoji text default '💄', tonos text[] default '{}', tags text[] default '{}', activo boolean default true, orden int default 0, created_at timestamptz default now() ); -- Storage bucket para imágenes insert into storage.buckets (id, name, public) values ('producto-fotos', 'producto-fotos', true); -- Políticas de acceso (ajusta según tus necesidades) create policy "Public read" on storage.objects for select using (bucket_id = 'producto-fotos'); create policy "Auth upload" on storage.objects for insert with check (bucket_id = 'producto-fotos'); create policy "Auth delete" on storage.objects for delete using (bucket_id = 'producto-fotos'); alter table categorias enable row level security; alter table productos enable row level security; create policy "Public read categorias" on categorias for select using (true); create policy "Public read productos" on productos for select using (true); create policy "Auth all categorias" on categorias for all using (auth.role() = 'authenticated'); create policy "Auth all productos" on productos for all using (auth.role() = 'authenticated');
3. Ve a Settings → API en Supabase y copia la URL del proyecto y la anon key.
4. También en Authentication → Users, crea un usuario con email y contraseña para el acceso al admin.
